# Agent instructions

1. Our "working" branch is master. Branches that we wish to merge to staging should follow naming convention `feature/fix-status-123`, `chore/fix-status-123` or `hotfix/fix-status-123`. Always summarize PR's, don't put "tests not run" in it. Name PR's sensibly, do not include agent name.
2. Do not add agent attribution to commits or PRs (no `Co-Authored-By` trailers for agents, no "Generated with ..." lines).
